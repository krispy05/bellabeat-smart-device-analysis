# Bellabeat Smart Device Usage Analysis

## Project Overview

This project analyzes Fitbit smart-device usage data to identify consumer behavior patterns and develop marketing insights for Bellabeat, a wellness smart-device company.

This project was completed as part of the Google Data Analytics Capstone case study.

## Business Problem

Bellabeat wants to use smart-device data to better understand consumer behavior and develop more targeted marketing strategies to support growth in the wellness smart-device market.

## Business Questions

1. What types of consumers are using smart devices, and who should Bellabeat target?
2. How should Bellabeat market its products based on consumer usage patterns?
3. What types of products or wellness features could be relevant based on consumer behavior?

## Tools Used

- Google BigQuery / SQL — data cleaning, processing and analysis
- Microsoft Excel — supporting analysis and visualizations
- Tableau Public — interactive dashboard

## Key Findings

- Average daily steps were approximately 7,638.
- Average daily calories were approximately 2,304.
- Activity was highest during the afternoon and evening, peaking around 6 PM.
- Higher-activity days were associated with lower sedentary time.
- Distance traveled had a positive relationship with recorded calorie expenditure (correlation ≈ 0.645).
- Sleep duration and activity showed only a weak negative relationship (correlation ≈ -0.19).
- Weekday and weekend activity levels were broadly similar.

## Recommendations

### 1. Target Lower-Activity Users

Encourage lower-activity users to gradually increase movement and reduce sedentary time.

### 2. Use Activity Timing

Use afternoon and evening activity patterns, particularly the 6 PM peak, as an opportunity to test targeted advertisements, reminders and engagement campaigns.

### 3. Promote Walking and Movement

Use the relationship between distance traveled and recorded calorie expenditure to promote walking and increased daily movement as part of Bellabeat's wellness messaging.

## Limitations

The analysis is based on observational Fitbit data from a relatively small sample and a limited time period. The relationships identified should not be interpreted as proof of causation.
