# Prepare

## Data Source

The project uses the Fitbit Fitness Tracker dataset provided for the Bellabeat case study.

## Data Used

The datasets used for the analysis include:

- Daily activity data
- Sleep data
- Daily calorie data
- Daily step data
- Daily intensity data
- Hourly intensity data

## Data Storage

The raw datasets were imported into Google BigQuery and stored as separate raw tables within the `daily_activity` dataset.

## Dataset Overview

The main daily activity dataset contains 940 records from 33 users and covers April 12 to May 12, 2016.

The sleep dataset contains data from 24 users.

## Purpose

These datasets were selected because they provide information about user activity, steps, distance, calories, intensity, 
sedentary behavior, hourly activity patterns & sleep. These variables were relevant to answering the business questions 
defined in the Ask phase.
